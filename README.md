## 🎯 Overview

1971WIN BD is a full-featured sports betting and crash game web platform built with React. The name "1971" honors Bangladesh's Liberation War — a symbol of strength, pride, and victory.

**Tagline:** *Bet Bold. Win Big. Since '71.*

---

## ✨ Features

### 🔐 Authentication
- Login / Register with OTP flow
- Password strength meter
- Referral code support

### ⚽ Sports Betting
- Live & upcoming matches (Football, Cricket, Basketball, Tennis, Kabaddi)
- SportyBet-style odds buttons (1 / X / 2)
- Live scores with animated indicators
- Bet slip with accumulator support + 5-20% boost
- Bet history (Pending / Won / Lost)

### 💥 Crash Game
- Real-time SVG animated multiplier curve
- Dual bet panels (Bet A + Bet B)
- Auto cashout with target multiplier
- Live players table with win/bust states
- Round history chips (color-coded by value)
- Live in-game chat

### 🎰 Casino
- 12 game cards (Slots, Live, Table, Crash, Fishing)
- Featured game banner
- Category filter + search

### 💰 Wallet
- Deposit / Withdraw with Bangladesh payment methods:
  - 💚 **bKash** | 🟠 **Nagad** | 🔵 **Rocket**
  - 🏦 Bank Transfer | ₿ USDT/Crypto | 💳 Card
- Real-time balance updates
- Full transaction history

### 🎁 Promotions
- 100% Welcome Bonus (up to ৳5,000)
- Daily Reload (20%)
- Referral Program (৳200/friend)
- Accumulator Boost (5–20%)

### 👑 VIP / Loyalty
- 5 tiers: Bronze → Silver → Gold → Platinum → Elite
- Points tracker with progress bar
- Per-tier cashback & perks

### 👤 Account
- Profile editing + KYC verification
- Security (password, 2FA, active sessions)
- Notification preferences

### 🛠️ Admin Panel
- Dashboard with live stats & bar chart
- Match management + manual settlement
- User management (suspend/reactivate/balance)
- Transaction approval/rejection
- Promotions management

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:5173](http://localhost:5173)
